**Course code:** CEN2016  
**Level:** Bachelor  
**Years taught:** 2022–2023, 2023–2024, 2024–2025, 2025–2026

This course introduces students to the core concepts and methods of data science, including data collection, cleaning, exploration, and analysis. Students gain hands-on experience with statistical methods and machine learning techniques for extracting insights from real-world datasets.

**Topics covered:**
- Data collection and preprocessing
- Exploratory data analysis and visualisation
- Statistical methods for data analysis
- Introduction to machine learning
- Data science tools and workflows
